## About

I'm a final-year Computer Science student building machine-learning systems that are meant to run in the real world — not just in a notebook. My work spans **NLP and RAG systems**, **anomaly detection**, and the **data-engineering and MLOps** that make models deployable and maintainable. I care a lot about evaluation rigor: measuring what actually generalizes, not just what scores well on a random split.

I'm especially interested in **Arabic / MENA-focused NLP** and in the infrastructure side of ML — pipelines, orchestration, and reliable deployment.

## Featured Projects

### 🏆 IntelliShift — End-to-End Data Platform · *1st place, Data Intelligence Track*
A full data platform built on a retail dataset, from raw ingestion to executive dashboards.
- **Two-layer schema architecture:** normalized 3NF OLTP + denormalized star-schema OLAP
- **Orchestration & infra:** Apache Airflow DAGs, Docker Compose, modular validated ETL in Python
- **Analytics:** RFM + K-Means customer segmentation; enrichment with external demographic data
- **BI layer:** Power BI dashboard with Executive, Logistics, and Marketing views

`Python` · `Airflow` · `Docker` · `SQL` · `scikit-learn` · `Power BI`
🔗 **[View repository](https://github.com/yahianassar2005/Intellij-Hackathon)**

### 🥇 Arabic Aspect-Based Sentiment Analysis (ABSA) · *4th place, National Arabic NLP Hackathon*
Aspect-level sentiment classification for Arabic text.
- Fine-tuned **AraBERT** for aspect-based sentiment
- **Dynamic threshold calibration** to handle class imbalance and boundary cases

`Python` · `PyTorch` · `AraBERT` · `Transformers` · `NLP`
🔗 **[View repository](https://github.com/yahianassar2005/DeepX-Hackathon)**

### 📱 Human Activity Recognition — Classical ML → Deep Learning → Attention
Classifying six activities from smartphone inertial sensors on the UCI HAR dataset, with an emphasis on **honest evaluation**.
- **Cross-subject `GroupKFold`** evaluation to measure real generalization (not subject leakage)
- Progression from Gradient Boosting → transfer-learning CNN → **BiLSTM + Attention**
- Best model: **~94% accuracy**, with domain-shift quantified across subjects

`Python` · `TensorFlow/Keras` · `scikit-learn` · `Time-Series`
🔗 **[View repository](https://github.com/ziad-walid/Human-Activity-Recognition)**

### ❤️ Heart Disease Predictor — Full ML Pipeline + Streamlit App
End-to-end supervised-learning pipeline with an interactive deployment.
- Preprocessing → PCA → feature selection → model comparison → hyperparameter tuning
- Best model: tuned Logistic Regression — **85.9% accuracy · 0.91 ROC-AUC**
- Multi-page **Streamlit** app for real-time prediction and data exploration

`Python` · `scikit-learn` · `Streamlit` · `PCA` · `Plotly`
🔗 **[View repository](https://github.com/ziad-walid/Heart-Disease-Predictor)**
